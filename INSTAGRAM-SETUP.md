# Instagram для Bright Feed — инструкция

## Что уже работает само (ничего делать не нужно)

- Каждый день в 11:30 UTC (14:30 по Москве) GitHub автоматически рисует **3 фирменные карточки** с лучшими позитивными новостями дня + готовые подписи с хэштегами.
- Смотреть и скачивать: **https://brightfeed.vercel.app/instagram** (страница скрыта от поисковиков, это твой рабочий инструмент).
- Аватар для профиля: **https://brightfeed.vercel.app/brand/instagram-avatar.png**

Карточки — это наш собственный дизайн (заголовок + указание источника), чужие фотографии в них не используются, так что с авторскими правами всё чисто.

## Шаг 1. Создать аккаунт — это можешь сделать только ты (~5 минут)

Instagram требует телефон/подтверждение личности, поэтому аккаунт заводит владелец.

1. Приложение Instagram → **Sign up**. Email подойдёт vadimkovalev999@gmail.com.
2. Username — пробуй по порядку, пока форма не покажет «свободно»: `brightfeed` (вдруг повезёт) → **`thebrightfeed`** (наш основной вариант) → `brightfeed.daily` → `brightfeed.world`. Когда зарегистрируешь — скажи Claude итоговое имя, чтобы добавить @упоминание в подписи карточек.
3. Профиль → **Edit profile**:
   - **Фото** — скачай аватар по ссылке выше.
   - **Name:** `Bright Feed ☀️ Good News`
   - **Bio** (скопируй):
     ```
     ☀️ Only good news, every day
     💛 Kindness 🌿 Planet ✨ Science 🐾 Animals
     👇 Today's full stories
     ```
   - **Link:** `https://brightfeed.vercel.app`
4. Обязательно: Настройки → **Account type and tools → Switch to professional account → Creator**, категория News/Media. Это бесплатно и нужно для статистики, планировщика и автопостинга.

## Шаг 2. Ручной режим — 2 минуты в день

1. С телефона открой https://brightfeed.vercel.app/instagram
2. Сохрани карточку (долгое нажатие → Save / кнопка «Скачать картинку»).
3. Кнопка «Скопировать подпись».
4. Новый пост в Instagram → вставь картинку и подпись → опубликуй.

Можно выложить и все 3 карточки одной каруселью — общая подпись есть внизу страницы.

**Лайфхак:** у professional-аккаунтов прямо в Instagram есть отложенные посты (при публикации → Advanced settings → Schedule). Раз в пару дней можно запланировать несколько постов за 10 минут.

## Шаг 3 (по желанию). Полный автопилот — пост выходит сам каждый день

Скрипт уже написан и ждёт в репозитории. Нужно один раз получить ключи (~30 минут):

1. Зайди на **developers.facebook.com** → войди (регистрация по тому же email) → **My Apps → Create App**. Тип/use case — Business (или «Other → Business»), имя приложения — например `Bright Feed Publisher`.
2. В приложении добавь продукт **Instagram** → выбери **API setup with Instagram login** (вариант без привязки Facebook-страницы).
3. В разделе генерации токенов нажми **Add account** → войди в Instagram-аккаунт Bright Feed → **Generate token** → скопируй:
   - **Instagram account ID** (число),
   - **access token** (очень длинная строка). Приложение может оставаться в Development mode — для своего аккаунта этого достаточно.
4. Открой **github.com/llcprimaire-beep/bright-feed → Settings → Secrets and variables → Actions → New repository secret** и создай два секрета:
   - `IG_USER_ID` — вставь Instagram account ID
   - `IG_ACCESS_TOKEN` — вставь токен
5. Готово. Со следующего дня workflow будет сам публиковать первую карточку дня. Проверить сразу: вкладка **Actions → Instagram Cards → Run workflow**.

⚠️ **Токен живёт ~60 дней.** Если посты перестали выходить — сгенерируй новый токен (пункт 3) и обнови секрет `IG_ACCESS_TOKEN`. Интерфейс Meta периодически меняется: если что-то выглядит иначе — пришли мне скриншот, помогу.

Это официальный Instagram API (никаких «ботов»), 1 пост в день — безопасный и комфортный темп.
